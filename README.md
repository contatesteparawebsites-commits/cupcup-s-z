# Corredor Liminal

Experiência liminal em Three.js com 18 portas interativas e progressão de dreamcore para weirdcore.

## Controles

WASD move o jogador.

Mouse olha ao redor.

E abre uma porta próxima.

Clique abre uma porta próxima quando o mouse está travado.

ESC ou o botão Voltar fecha a imagem e retorna ao corredor.

## Imagens

As 18 cenas são carregadas da internet por URLs de imagens remotas para manter o projeto em um único `index.html`. As buscas seguem a progressão visual de quarto pastel, playground, piscina, escola e espaços vazios até corredores, neon, glitch e arquitetura abstrata.

## Projeto

O jogo usa Three.js r128 via CDN e funciona como uma página estática.
